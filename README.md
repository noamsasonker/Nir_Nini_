# ניר ניני | הנדסאי אדריכלות - אתר תדמית ופורטפוליו מקצועי

אתר אינטרנט יוקרתי, נקי ומודרני עבור **ניר ניני, הנדסאי אדריכלות**, המותאם במדויק לשפה העיצובית ולמיתוג הרשמי. האתר מתמקד בתכנון וילות יוקרה צמודות קרקע, הדמיות תלת-ממד מתקדמות והוצאת היתרי בנייה ורישוי.

---

## ✨ מאפיינים ודגשים מרכזיים

1. **מבנה גלריה מפוצל (Landing Page Preview & Full Dedicated Gallery):**
   - **בדף הנחיתה (`index.html`):** מוצגות בדיוק 2 תמונות נבחרות של חזיתות הוילה במבנה נקי ומאוזן, ומתחתן כפתור בולט ומעוצב: **"לגלריה מלאה"**.
   - **בעמוד הגלריה הנפרד (`gallery.html`):** מוצגות כל 9 ההדמיות המקוריות ברזולוציה גבוהה, עם סינון לפי קטגוריות (חוץ ופיתוח נוף, סלון וחלל מרכזי, מטבח ואירוח), קישור חזרה לדף הבית, ומודאל מפורט עם זום (Lightbox).

2. **מצב בהיר קבוע (Permanent Light Mode):**
   - האתר כולו מוצג במצב בהיר, נקי ומינימליסטי בגווני לבן ואפור אדריכלי רך (`#ffffff` / `#f8f9fa`) עם טיפוגרפיה כהה וקריאה (`#111216`).
   - ללא אפשרות מעבר למצב כהה וללא תלות בהגדרות מערכת ההפעלה.

3. **אזור יצירת קשר שחור יוקרתי (The Exclusive Black Contact Zone):**
   - בהתאם להנחיות, אזור יצירת הקשר והטופס מעוצב ברקע שחור עמוק (`#0b0c10`), המהווה את החריג היחיד באתר ומעניק נוכחות יוקרתית.
   - שדות קלט כהים (`#1b1e2a`), טקסטים בהירים וקריאים, וכפתור שליחה מוזהב בגוון פליז יוקרתי.

4. **סרטון וידאו אותנטי במסך הפתיחה:**
   - סרטון סיור אדריכלי תלת-ממדי אמיתי (`assets/videos/hero-background.mp4`) המתנגן בלופ אינסופי, ללא קול, על גבי כל שטח מסך הפתיחה, עם שכבת הצללה מעודנת לקריאות מושלמת של הטקסטים.
   - תמונת גיבוי אותנטית להבטחת טעינה חלקה בכל המכשירים.

5. **100% תמונות והדמיות מקוריות:**
   - כל 9 ההדמיות שסופקו מוצגות בעמוד הגלריה:
     1. חזית וילה מודרנית ופיתוח שטח (`villa-exterior.jpg`)
     2. חזית אבן טבעית, ויטרינות ובריכה (`villa-stone-facade.jpg`)
     3. מבט ממעוף הציפור ומרפסת קומה עליונה (`villa-aerial-balcony.jpg`)
     4. פטיו אירוח, פרגולה ודק עץ (`villa-patio-pergola.jpg`)
     5. שביל גינה, קיר ירוק וצמחייה (`villa-garden-path.jpg`)
     6. סלון מרווח, מדרגות מרחפות וגוף תאורה מעגלי (`villa-living-wide.jpg`)
     7. מבואת כניסה עם מדרגות מרחפות ומבט לגינה (`villa-hall-stairs.jpg`)
     8. פינת ישיבה וסלון המשקיף לבריכה (`villa-living-sofa.jpg`)
     9. מטבח מודרני, אי שיש וארונות שחורים (`villa-kitchen.jpg`)
   - כל תמונות הסטוק, תמונות ה-AI והתוכן המומצא הוסרו לחלוטין.

6. **אייקונים רשמיים לרשתות החברתיות ופרטי התקשרות:**

## 🚀 הפעלה מקומית

האתר נבנה בטכנולוגיות Web סטנדרטיות ואינו דורש תלויות חיצוניות.

### אפשרות א': פתיחה ישירה בדפדפן
- לחצו פעמיים על `index.html` בכל דפדפן (Chrome, Edge, Safari, Firefox).

### אפשרות ב': הרצת שרת מקומי ב-Python
```powershell
python -m http.server 8000
```
לאחר מכן גלשו לכתובת:
👉 **`http://localhost:8000`**
